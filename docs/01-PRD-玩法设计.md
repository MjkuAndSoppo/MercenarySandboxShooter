# PRD · 玩法设计文档

**项目名**：MercenarySandboxShooter（Mod ID：`msb`）
**类型**：Minecraft Java 版 NeoForge 端 Mod（SuperbWarfare 必要附属模组）
**核心目标**：把《WARDOGS》（BULKHEAD，2026）的核心体验移植进 Minecraft —— 在三方阵营的大型军事沙盒中，围绕「控制区争夺 + 建造破坏 + 现金经济」形成高密度、可复盘的战场循环。
**文档版本**：v0.1（初始探讨稿）
**状态**：待评审（版本定位已定：1.21.1 基线；发布策略已定：公开但禁止二次分发）

---

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 一句话定位 | 在 Minecraft 里做一个「WARDOGS 式」三方阵营争夺战 Mod：占区计分、造掩体拆掩体、用现金配置每一场战斗 |
| 参考对象 | WARDOGS（100 人 FPS 沙盒）：三阵营 KotH 计分、Hot Zone 权重、塔楼/钻井台拉战区、FOB 前哨建造、现金配装经济 |
| 载体优势 | MC 原生「建造/破坏方块」能力 = WARDOGS 的工事系统天然适配；区块世界 = 大地图战场 |
| 引擎/端 | NeoForge（版本待定，见 03-版本定位） |

## 2. 目标与非目标

### 目标
- 一局内可玩：出生 → 战斗/占点 → 赚现金 → 配置下一条命 → 建造/升级 FOB → 打满 100 分获胜。
- 三方阵营同时对抗（不是两队），计分驱动玩家向同一战区聚集。
- 建造与破坏影响战局（掩体、复活点、拉战区装置），而不只是装饰。
- 现金经济让「死亡损耗（装备折算 / 本命收入清零）+ 每局再投资」成立，形成长线解锁 + 短线战术的双层激励。

### 非目标（P0 不做）
- 载具（坦克/直升机）—— 留作 P1/P2 扩展（见 03 里程碑）。
- 写实弹道/后座模拟 —— 保持 MC 手感，做「轻量战斗层」。
- 完整 RPG 养成 —— 不做技能树/装备掉落，经济即进度。
- 超大规模真实同服（100 人级）—— MC 服务器上限现实，按 30 真人 + AI 填充设计，逻辑可扩展。

## 3. 核心玩法支柱（用户已确认三项）

| 支柱 | 说明 | 对应 WARDOGS 机制 |
|---|---|---|
| P1 三阵营 + 控制区计分 | 地图固定控制区，每 30s 区内人数最多的阵营 +1 分，先到 100 胜；小范围 Hot Zone 内人数按 2 倍计、收益翻倍；3~5 座塔楼集码可把控制区拉向己方塔楼；FOB 可造钻井台把区拉向己方 | KotH 控制区 / Hot Zone / Tower Code / Drill Rig |
| P2 建造与破坏 | FOB（前哨锚点）解锁建造权限：沙袋墙、碉堡、弹药箱、复活信标、雷达塔、钻井台等；方块有耐久，可被摧毁；摧毁敌方工事得赏金 | FOB / 工事 / 建造与破坏 |
| P3 经济系统 | 现金贯穿全循环：击杀/占区/热点/摧毁工事赚钱；买枪械、护甲、消耗品构成配装；配装带负重影响移动；死亡不掉落（装备按卖价六折折算给击杀者 / 其他死因重生返还）、现金永不丢失；账号级解锁让装备「可购买」而非免费 | Cash / Loadout / Weight / 死亡结算 |

> 战斗层（默认假设，待确认）：P0 含一套轻量枪械+弹药（作为经济消费的载体），复用 MC 攻击手感改造，不引入写实弹道。若你倾向「零枪械、纯 MC 战斗」，经济消费将落到护甲/工事/消耗品上 —— 列为开放问题 O1。

## 4. 三阵营设计

| 阵营 | 主色 | 定位 | 阵营增益（人力/火力/补给/上限） | 数值倾向 |
|---|---|---|---|---|
| Lonestar 孤星（S.F 铁血工业制造） | 红 #ff5a4d | 攻坚 / 火力 | 5 / 5 / 3 / 2 | 攻击 ★★★☆ 防御 ★★☆☆ |
| Valkyra 女武神（KCCO 新苏联特战部） | 蓝 #4d9eff | 防御 / 机动 | 2 / 4 / 5 / 4 | 攻击 ★★☆☆ 防御 ★★★☆ |
| Manticore 蝎狮（I.O.P 重要原型制造） | 绿 #4ade80 | 侦察 / 经济 | 4 / 3 / 3 / 5 | 攻击 ★★☆☆ 防御 ★★☆☆ |

- **阵营增益（2026-10-03 落地）**：四项数值（人力/火力/补给/上限，取值 0~5）写入 `Faction` 枚举，并在**开局选择手册界面展示**（界面已标注「预览」）；当前**先只做展示与数据结构，暂不接实际效果**（后续按里程碑接入）。
- 阵营 = Minecraft 计分板队伍（名字染色），`Faction` 枚举与队伍双向映射。
- **开局由玩家自选阵营**（2026-10-03）：进入世界无阵营 → 获得雇佣兵手册 → 手册内三选一（不再自动分配）；选择时显示以上阵营增益。
- 敌我识别（IFF）：名字标签阵营染色 + 准星目标 IFF 面板（名称/阵营色/血条/距离）；允许友伤但伤害砍半；命中友军按次、按伤害量扣款（受害队友无补偿）；若造成友军击杀 → 受害队友获补偿、攻击者追加罚款 ×n（n 待平衡）；探测标记沿用同一判定（详见 02 技术文档 §3.10）。
- ~~每局阵营人数动态平衡（1.1 倍赏金）~~ 为早期设想，**未实现**（原自动分配逻辑已随开局流程移除）。

## 5. 对局流程（单局核心循环）

```
进入世界（无阵营）→ 自动获得「雇佣兵手册」→ 右键打开，选择：阵营（三选一，含阵营增益展示）
                                              + 初始资金档位 + 初始 AI 数量（5~15）
   ↓
传送到所选阵营基地 → 开始游戏（该阵营无基地配置时提示并跳过传送）
   ↓
争夺控制区（每 30s 计分）←→ 抢占 Hot Zone（2倍权重+双倍现金）
   ↓
击杀敌人 / 摧毁敌方工事 / 占塔集码 → 赚现金
   ↓
现金投入：配装（枪械/护甲/消耗品）｜建造（FOB→工事→钻井台）
   ↓
任意阵营先到 100 分 → 本局结束 → 结算（战绩/现金结转）→ 下一局
```

**开局三选项（2026-10-03 落地）**：
- **阵营**：三选一，界面同时显示四项阵营增益（见 §4）。
- **初始资金档位**（与 AI 数量相互独立）：3000$ / 8000$ / 20000$；**初始资金越高，后续击杀收益倍率越低**（×1.5 / ×1.0 / ×0.8）——高资金起手强但击杀变现弱，低资金靠击杀滚雪球。
- **初始 AI 数量**：5~15；数量多 → 占点/控场优势，数量少 → 经济/资源更集中（该阵营开局 AI 编制，首个选择者写入后固定）。
- **Tab 键信息栏**（预留）：随时呼出，页签 阵营 / 战绩 / 队伍 / 教程（当前为骨架占位）。
- **开局门槛（2026-10-04 决策，✅已实现）**：三阵营**均确认 AI 数量后**方可开始对局（门槛达成前 AI 不生成、控制区不计分）；OP 可用 `/MSBS game start` 强制开始（未选择的阵营自动取**最大 AI 数量 15**）。
- **队伍指挥（暂定 M3）**：**首个选择某阵营的玩家**成为该阵营指挥官；后续可经**投票或转让**变更。

### 5.1 阵营基地方块（安全区）

- **基地方块**：三阵营各有一座基地方块（放置于各自出生点附近，同 FOB 可分离），是该阵营的安全核心。
- **范围**：以方块为中心、半径 16 格画圆（XZ 平面判定），无高度/深度限制（即整条垂直柱状安全柱）。
- **规则**：范围内本方阵营玩家**无敌**（免疫全部伤害来源）；敌方玩家可进入但无法造成伤害；已生效的持续伤害（着火/中弹后溢出）规则待定。
- **意图**：提供可靠的出生/回防安全点，防止出生点压制与远程蹲杀，让战斗围绕圈外与控制区展开。
- **边界**：无敌仅限本方阵营；基地方块本身可破坏（归属建造体系，见 §7），方块被拆则安全区失效、敌方可顺势突入。
- **载具（卓越/ SBW 提供）**：安全区内本方载具同样无敌，且缓慢恢复（血量/耐久缓慢回满）；驶出圈即恢复可伤。
- **放置约束（2026-10-04 决策）**：基地方块**不可放入控制区圆内**（防造「圈内无敌区」），违规放置被取消并提示；同阵营基地间距等其余约束留待 M3 FOB 体系一并设计。

## 6. 控制区计分规则（核心数值）

- **控制区**：每局圈定一个 **512 方块级区域**（半径 ≈256 格，`controlZoneRadius` 可配 16~512，默认 256）。每 30s 结算一次：区内存活人数最多的阵营 +1 分，平局不加分。先到 100 分获胜。
- **Hot Zone**：控制区内的移动小圈。站入者计 2 人、赚取 2 倍现金。每 45s 随机迁移一次（方向偏好当前人数劣势区）。
- **塔楼（Tower）**：3~5 座，交互终端获得 1 位码字；集齐 4 位后输入，控制区被拉向己方已占领的塔楼。塔楼可被敌方破坏并重建。
- **钻井台（Drill Rig）**：FOB 建造后需燃料持续供应；生效期间把控制区拉向 FOB，同时向全图广播，等于邀请三方来攻。
- **计分表现**：与 WARDOGS 对齐 —— 一次 30s 结算的权重远高于圈外打赢一场遭遇战；Hot Zone 4 人 = 圈外 8 人的权重。

## 7. 建造与破坏

- **FOB（Forward Operating Base）**：队伍花钱放置的锚点方块，是建造权限的「根」。可升级等级（I/II/III）解锁更高级工事。
- **工事目录（P0 首版）**：

| 工事 | 成本 | 耐久 | 解锁 | 作用 |
|---|---|---|---|---|
| 沙袋墙 | $800 | 低 | I | 掩体，可堆叠 |
| 铁丝网 | $500 | 低 | I | 减速+伤害敌方 |
| 弹药箱 | $1,200 | 中 | I | 己方补给弹药 |
| 复活信标 | $3,000 | 中 | II | 缩短/设置出生点 |
| 碉堡 | $4,500 | 高 | II | 坚固掩体+射击孔 |
| 雷达塔 | $2,800 | 中 | II | 探测小地图敌方红点 |
| 钻井台 | $8,000 | 高 | III | 拉控制区，需燃料 |

- 破坏：方块带耐久与方块破坏保护（PvP 下使用独立伤害系统），摧毁敌方工事全额赏金、己方工事回收 50%。
- 交互承载：BlockEntity + 自定义方块（带碰撞/耐久），复用 MC 挖掘但替换为定制破坏逻辑。

## 8. 经济系统

- **起始资金（2026-10-03 落地）**：开局在手册内选择档位——3000$ / 8000$ / 20000$，对应击杀收益倍率 ×1.5 / ×1.0 / ×0.8（**资金越高、击杀变现越低**）；**倍率适用范围（2026-10-04 决策）= 击杀赏金 + 控制区占区结算**（Hot Zone 翻倍、摧毁工事、占塔码等一次性事件不乘；占区收益本身仍为规划项）。
- **击杀赏金（已实现分档）**：敌方玩家 100$ + 目标每击杀 ×100；怪物/生物 100$ + 每击杀 ×50；敌方阵营 AI 200$ + 每击杀 ×100；**实际入账再乘本人击杀收益倍率**（仅正奖励，友伤罚款不缩放）。经验 15 + 每击杀 ×5（不受倍率影响）。
- **收入（规划项）**：击杀（上） / 助攻 $100 / 控制区结算内 $150 / Hot Zone 内翻倍 / 摧毁工事 $400~800 / 占塔码 $500。
- **支出**：配装（枪械/护甲/消耗品，M2 已实现商店）、工事、塔楼重建、钻井台燃料、友伤罚款（每次命中按伤害量计罚，如每 1 伤害 $20；友军击杀追加罚款 ×n 并向受害队友补偿；非致命扣款与同阵营 AI 击杀罚款已落地）。
- **配装与负重**：每件装备有负重；总负重超阈值 → 移速下降、跳跃受限（M2 已实现，60% 起减速、100% 封顶并禁买）。
- **死亡**：阵营玩家死亡一律不产生地面掉落（M2 落地口径：被敌方击杀时装备按卖价六折折算成赏金给击杀者，其他死因装备重生返还）；现金永不丢失（总资产跨死亡保留、仅本命收入清零）。
- **账号级解锁（P1）**：杀敌/占区累计经验解锁装备「购买资格」，但每次仍要付现金 —— 分层激励，杜绝「毕业即无事可做」。

## 9. 范围分级（P0 / P1 / P2）

**P0（可玩闭环）**：阵营+队伍、**开局流程（雇佣兵手册：阵营三选一 + 初始资金档位 + 初始 AI 数量 + 开局传送，见 02 §3.14）**、**Tab 信息栏（预留骨架）**、控制区/Hot Zone 计分、塔楼集码、SBW 联动层（枪械/弹药/载具由 SBW 提供；本 mod 负责阵营/占区/经济/工事/IFF，见 02 §3.11）、AI 玩家填充（PvPvE，AI 数量由开局选择固定、不带真人顶替，见 02 §3.12）、现金经济+配装+负重、FOB+5 种基础工事、结算界面、HUD（计分板/计时/热点/现金）、敌我识别（阵营标签 + 准星 IFF 面板）、NeoForge 网络同步、基本防作弊（服务端权威）。

**P1**：钻井台+燃料、雷达塔、复活信标细化、账号级解锁、保险券、击杀回放/战绩统计、动态地图（小地图）、阵营平衡自动分配、GeckoLib 动画化实体、**远距玩家可见性方案（标记系统 + 名字标签距离放宽，见 02 技术文档 §3.9）**。

**P2**：载具（由 SBW 提供，本 mod 做购买/阵营归属/损坏赏金）、空中支援、语音/无线电、Modpack 集成。
